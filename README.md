# Nachtflug

Eine Demo von Hans Schnorrenberger, geschrieben in
[Drachenhauch](https://github.com/HasoSchno70/Drachenhauch): Trance in a-Moll
von a-Moll nach C-Dur, gut viereinhalb Minuten: vom nächtlichen Meer über
die Berge durch einen Lichttunnel ins All zur Galaxie -- und wieder heim:
Erdaufgang im Orbit, Wiedereintritt, über den Wolken mit einem Zug
Wildgänse, an der Küste mit dem Leuchtturm vorbei bis zum Tagesanbruch auf
dem Meer. Musik und Bild entstehen beide im Programm selbst.

**Im Browser ansehen:** https://hasoschno70.github.io/Nachtflug/

In diesem Repository liegt die Browser-Fassung: die Drachenhauch-Laufzeit
`dhrt` als WebAssembly (`dhrt.wasm`, `dhrt.js`, `dhrt.data` mit den Shadern)
und die Quelle `program.dh`, die beim Start im Browser übersetzt wird.
Tipp: einmal klicken (Browser spielen Ton erst nach einem Klick), Kopfhörer
aufsetzen, ⛶ für Vollbild.

Die Lizenzen der in `dhrt.wasm` enthaltenen Bibliotheken stehen in
[THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt).
